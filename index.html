☁️ Tetapan Awan (GitHub Gist)

Simpan data RPH anda ke GitHub Gist supaya boleh diakses dari mana-mana peranti.

📖 Cara Setup (sekali sahaja):
  1. Pergi ke gist.github.com → login GitHub
  2. Cipta Gist baharu → Nama fail: rph_data.json → Isi: {} → Create secret gist
  3. Salin Gist ID dari URL (bahagian akhir)
  4. Pergi ke github.com/settings/tokens → Generate new token (classic) → Skop: gist
  5. Salin token dan tampal di bawah
Dari URL Gist anda — bahagian selepas nama pengguna
